# PIER 7 — ブラウザFPS

5つのマップで遊べるFPSです。個人戦（フリー・フォー・オール）と、1v1〜5v5のチーム戦があります。three.js（ES Modules）で書かれていて、ビルドなしでそのまま動きます。
オンライン対戦は、同梱の Node.js サーバー（WebSocket）、無料の公開中継サーバー（GitHub Pages などサーバーのない場所で自動的に使用）、claude.ai のアーティファクト内のオンライン機能のどれかを使います。

## 遊び方の流れ

1. **起動画面** — 読み込みが終わったらクリック／タップで開始（ここで音声が有効になります）。初回はお名前（コールサイン）を入力します。名前は一か月に一回しか変更できず、決定前に確認が出ます
2. **ロビー** — 武器を選び、遊んでいるロビーの一覧から参加、「ランダム参加」（空いているロビーへ。なければ自動で作成。モードで絞り込み可）、または「ロビーを作成」。フレンドはコードを交換して追加すると、オンラインかどうか・どのロビーで遊んでいるかが表示され、そのまま参加できます
3. **ロビーを作成** — ロビー名、マップ（5種）、モード（オンライン／オフライン＝Botマッチ）、ルール（個人戦／1v1／2v2／3v3／4v4／5v5）、Bot（オフ／数）と強さ、HP（100／150／200）、ダメージ（弱い／ふつう／強い）、キル回復（オフ／+50／+150）を選ぶ。オンラインでも Bot・HP・ダメージ・キル回復はロビーを作った人（ロビー主）だけが決め、試合中も一時停止メニューから変更できます。ほかの人は変更できず、ロビー主が抜けてもそのルールのまま続きます（Bot をオフにしたロビーに Bot が勝手に入ることはありません）
4. **接続画面** — オンラインならサーバーに接続 → ロビーに参加 → マップ読み込み、オフラインならその場で起動
5. **マッチ** — 一時停止メニューの「ロビーに戻る」でロビーへ。倒されると、倒した相手を後ろから映すキルカムになります

### チーム戦（1v1〜5v5）

- ブルーとレッドの2チームに自動で分かれます（あとから入った人は人数の少ないチームへ。新しいマッチの開始時に人数をそろえ直します）。
- 味方への攻撃（銃・グレネード・近接）は当たりません。味方はミニマップに常に表示され、名前も壁越しに見えます。
- 先に目標キル数（1v1: 10 / 2v2: 20 / 3v3: 30 / 4v4: 40 / 5v5: 50）に届いたチームか、時間切れの時点で多いチームの勝ち。
- 定員（1v1 は2人、5v5 は10人）に達したロビーは一覧で「満員」になり参加できません。Bot はロビー主が入れた数までで、空いている枠にだけ入ります。

### 保存されるもの

設定・キー割り当て・ボタン配置・お名前・フレンド一覧・フレンドコードは、変更するたびにブラウザに自動保存されます（予備のコピーも保存）。ホーム画面に追加したアプリと Safari は保存場所が別なので、それぞれで設定されます。

オンラインに接続できないときは、勝手にオフラインへ切り替えずにエラーと「再試行」を表示します。

## すぐに遊ぶ（自前サーバー）

```bash
npm install
npm start          # → http://localhost:8080
```

同じネットワークの別端末からは `http://<このPCのIP>:8080`。ポートは `PORT=3000 npm start` で変更できます。
インターネットに公開する場合は、Node.js が動くホスティング（Render、Railway、Fly.io、VPS など）にリポジトリごと置いて `npm start` で起動してください。HTTPS で配信すると WebSocket も自動で `wss://` になります。

### GitHub Pages で公開する場合

**フォルダの形のままアップロードしてください。** `index.html` と同じ場所に `css/`・`js/`（中に `js/maps/`）・`server/`・`tools/` が並んでいる必要があります。
GitHub の「Add file → Upload files」でファイルを選んで追加するとフォルダが消えて全部が一番上に並び、画面が白いまま「読み込み中…」で止まります（`css/style.css` と `js/main.js` が見つからないため）。
エクスプローラーやFinderから **css フォルダと js フォルダごとドラッグ&ドロップ** するか、GitHub Desktop / `git push` を使ってください。
アップロード後に `https://<user>.github.io/<repo>/js/main.js` を開いて中身が表示されれば正しく置けています。
起動できないときは、起動画面に足りないファイルの名前が表示されます。

GitHub Pages ではサーバーを動かせないので、オンライン対戦は**無料の公開中継サーバー（MQTT）**を通して行います。設定は不要で、GitHub Pages のURLを開くだけで別の端末・スマホと対戦できます。
中継サーバーは HiveMQ・EMQX・Mosquitto・shiftr.io（443番ポート）のうち、つながるもの全部にロビー情報を流すので、端末ごとにつながる中継サーバーが違っても一覧に表示されます。マッチの通信は、ホストが使っている中継サーバー1つで行います。
ロビー画面の上に `ver 10/15d` のような表示が出ます。GitHub に新しいファイルを上げると、開いている端末のロビー画面に「新しい版に更新」ボタンが出るので、押すと最新のファイルを読み込み直します（ホーム画面に追加したアプリでも使えます）。
公開の中継サーバーなので、送っている内容（コールサイン・位置・チャットなど）は第三者からも見えます。個人情報は書かないでください。

自前のサーバーを使いたいときは、別の場所で `npm start` したサーバーの URL を `?server=` で、特定の MQTT ブローカーを使いたいときは `?relay=` で指定できます。

```
https://<user>.github.io/<repo>/?server=wss://your-server.example.com/ws
https://<user>.github.io/<repo>/?relay=wss://your-broker.example.com:8884/mqtt
```

  effects.js          曳光弾・マズルフラッシュ・着弾の火花と土煙・跳弾・弾痕・薬莢・爆発

  sfx-data.js         実銃の録音（下の「音源のクレジット」参照）
  hud.js, input.js    HUD・入力（キー割り当て、タッチ操作）
  settings.js         設定の項目と許容範囲（読み込み時に範囲内へ補正）
  settings-ui.js      設定画面（PCとスマホで別の項目）
  config.js           武器・移動・マッチ・Bot難易度の数値

three.js は `index.html` の importmap で CDN（jsDelivr）から読み込みます。

## 1ファイル版を作る

```bash
npm install
npm run build:artifact   # → dist/pier7-artifact.html と dist/pier7-single.html
```

`dist/pier7-single.html` はダブルクリックで開けます（公開中継サーバーを使ったオンライン対戦もできます）。

## オンライン同期のしくみ

- 各プレイヤーは自分の状態（位置・向き・体力・武器・キル数、直近の射撃/命中/キル/グレネード/チャットのイベント）を約30回/秒で送ります。
- ロビーにいる人は、自分がどのロビーで遊んでいるか（ロビーID・名前・マップ）を共有し、それがロビー一覧になります。
- ロビーを作った人（ロビー主）がいる間はその人がホストになり、Bot・マッチ時間・ラウンド・マップを担当します。参加した人はホストのマップと Bot 設定に合わせます。ロビー主が抜けると ID が最も小さい人が引き継ぎ、Bot 設定もそのまま引き継がれます。
- 命中判定は撃った側が行い、ダメージは撃たれた側（Bot はホスト）が適用します。サーバーは中継のみです（気軽に遊ぶ用途向けで、不正対策はありません）。
- 公開中継サーバー経由のときは、1秒に20回送信し、相手の動きを少し長め（0.15秒）にバッファして滑らかに表示します。通信が一瞬切れても自動で再接続します。

## 設定と公平性

PC では「操作・キー割り当て・映像・サウンド・HUD」、スマホでは「操作・ボタン配置・映像・サウンド・HUD」が表示されます。
HP とダメージの強さはロビーのルールとして全員に同じだけかかります（初期値は HP 150・ダメージふつう。アサルトライフルなら胴体6発ほど）。敵を倒すと HP が回復します（初期値 +150、最大 HP まで）。
反動・武器ごとの性能・移動速度は変更できず、全員に共通の反動（`js/config.js` の `FORCED_RECOIL`）がかかります（Bot も同じ）。視野角は 65〜90°、影・煙・霧はどの画質でも表示され、足音だけを大きくする設定もありません。保存された設定は読み込み時に許容範囲へ補正されます（`js/settings.js` の `SCHEMA`）。

## 操作（PC・初期設定）

| 操作 | キー |
|---|---|
| 移動 / ダッシュ / ジャンプ / しゃがむ | WASD / Shift / Space / C |
| 射撃 / ADS | 左クリック / 右クリック（歩きながらADSできます） |
| リロード / 武器切替 | R / 1・2・3・Q・ホイール |
| グレネード / 近接 | G / V |
| スコア / チャット / メニュー | Tab / Enter / Esc |

スマホ・タブレットでは画面左ドラッグで移動、右ドラッグで視点。射撃とADSのボタンは押したまま指を滑らせると視点も動かせます。ADS を押している間は、その指（人差し指など）を射撃ボタンの上に滑らせるだけで撃てます（タップし直す必要はありません）。右上の II で一時停止。
