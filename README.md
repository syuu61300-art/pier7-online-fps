# PIER 7 — ブラウザFPS

5つのマップで遊べるフリー・フォー・オールのFPSです。three.js（ES Modules）で書かれていて、ビルドなしでそのまま動きます。
オンライン対戦は同梱の Node.js サーバー（WebSocket）か、claude.ai のアーティファクト内のオンライン機能を使います。

## 遊び方の流れ

1. **起動画面** — 読み込みが終わったらクリック／タップで開始（ここで音声が有効になります）
2. **ロビー** — コールサインと武器を選び、遊んでいるロビーの一覧から参加するか「ロビーを作成」
3. **ロビーを作成** — ロビー名、マップ（5種）、モード（オンライン／オフライン＝Botマッチ）、Bot数と強さを選ぶ
4. **接続画面** — オンラインならサーバーに接続 → ロビーに参加 → マップ読み込み、オフラインならその場で起動
5. **マッチ** — 一時停止メニューの「ロビーに戻る」でロビーへ

オンラインに接続できないときは、勝手にオフラインへ切り替えずにエラーと「再試行」を表示します。

## すぐに遊ぶ（自前サーバー）

```bash
npm install
npm start          # → http://localhost:8080
```

同じネットワークの別端末からは `http://<このPCのIP>:8080`。ポートは `PORT=3000 npm start` で変更できます。
インターネットに公開する場合は、Node.js が動くホスティング（Render、Railway、Fly.io、VPS など）にリポジトリごと置いて `npm start` で起動してください。HTTPS で配信すると WebSocket も自動で `wss://` になります。

### GitHub Pages で公開する場合

**フォルダの形のままアップロードしてください。** `index.html` と同じ場所に `css/`・`js/`（中に `js/maps/`）・`server/`・`tools/` が並んでいる必要があります。
GitHub の「Add file → Upload files」でファイルを選んで追加するとフォルダが消えて全部が一番上に並び、画面が白いまま「読み込み中…」で止まります（`css/style.css` と `js/main.js` が見つからないため）。
エクスプローラーやFinderから **css フォルダと js フォルダごとドラッグ&ドロップ** するか、GitHub Desktop / `git push` を使ってください。
アップロード後に `https://<user>.github.io/<repo>/js/main.js` を開いて中身が表示されれば正しく置けています。
起動できないときは、起動画面に足りないファイルの名前が表示されます。

GitHub Pages は静的ファイルしか配信できないので、そのままだとオフライン（Botマッチ）だけ遊べます。
オンライン対戦もしたいときは、別の場所で `npm start` したサーバーを用意し、URL に `?server=` を付けて開きます。

```
https://<user>.github.io/<repo>/?server=wss://your-server.example.com/ws
```

three.js は `index.html` の importmap で CDN（jsDelivr）から読み込みます。

## 1ファイル版を作る

```bash
npm install
npm run build:artifact   # → dist/pier7-artifact.html と dist/pier7-single.html
```

`dist/pier7-single.html` はダブルクリックで開けます（オフラインのBotマッチのみ）。

## オンライン同期のしくみ

- 各プレイヤーは自分の状態（位置・向き・体力・武器・キル数、直近の射撃/命中/キル/グレネード/チャットのイベント）を約30回/秒で送ります。
- ロビーにいる人は、自分がどのロビーで遊んでいるか（ロビーID・名前・マップ）を共有し、それがロビー一覧になります。
- ロビーの中で ID が最も小さい人がホストになり、Bot・マッチ時間・ラウンド・マップを担当します。参加した人はホストのマップに合わせます。ホストが抜けると次の人が引き継ぎます。
- 命中判定は撃った側が行い、ダメージは撃たれた側（Bot はホスト）が適用します。サーバーは中継のみです（気軽に遊ぶ用途向けで、不正対策はありません）。

## 設定と公平性

PC では「操作・キー割り当て・映像・サウンド・HUD」、スマホでは「操作・ボタン配置・映像・サウンド・HUD」が表示されます。
反動・武器性能・移動速度は変更できず、全員に共通の反動（`js/config.js` の `FORCED_RECOIL`）がかかります（Bot も同じ）。視野角は 65〜90°、影・煙・霧はどの画質でも表示され、足音だけを大きくする設定もありません。保存された設定は読み込み時に許容範囲へ補正されます（`js/settings.js` の `SCHEMA`）。

## 操作（PC・初期設定）

| 操作 | キー |
|---|---|
| 移動 / ダッシュ / ジャンプ / しゃがむ | WASD / Shift / Space / C |
| 射撃 / ADS | 左クリック / 右クリック（歩きながらADSできます） |
| リロード / 武器切替 | R / 1・2・3・Q・ホイール |
| グレネード / 近接 | G / V |
| スコア / チャット / メニュー | Tab / Enter / Esc |

スマホ・タブレットでは画面左ドラッグで移動、右ドラッグで視点。射撃とADSのボタンは押したまま指を滑らせると視点も動かせます。右上の II で一時停止。
